# Servo-Tester
This is a tool where you can test if servos work or not
the parts you will need are a breadboard or a blank pcb a servo a potentiomiter a aurdino nano and aurdino installed on your computer and a usb cable

to set it up conennet the power to 5v and ground to gnd for the servo and potentiomiter then connect the last potentiomiter pin to A0 and the servo pin to D2 then istal the code and everything should work
